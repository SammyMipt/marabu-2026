# Марабу 2026 — веб-презентации лекций

Две лекции для лагеря Марабу (Массачусетс, лето 2026):

- **«Электрон»** — квантовая механика, младшая группа (11–14). Часть миникурса Сергея, третья лекция из четырёх.
- **«Течения и турбулентность»** — классическая физика, старшая группа (14–18). Полностью standalone.

Каноничные планы лекций: `lekciya_elektron_plan.md`, `lekciya_turbulentnost_plan.md`, полный контекст решений — `marabu_kontekst.md`. Контент слайдов следует планам дословно; отклонения — только через явное обсуждение.

**Продолжая работу, начните с [WORK.md](WORK.md)** — там текущее состояние по беатам, порядок работы, принятые решения и карта готовых демок в `Demo/`.

## Как открыть

Никакой сборки нет. Открой `index.html` (лендинг) или сразу колоду:

- `elektron/index.html`
- `turbulentnost/index.html`

Работает с диска (file://) и без интернета — это принципиальное требование: в лекционном зале сети может не быть.

## Управление на лекции

| Действие | Клавиша |
|---|---|
| Слайды вперёд/назад | стрелки, пробел, PageDown/PageUp (кликер) |
| Режим докладчика (заметки + таймер + следующий слайд) | `S` |
| Полный экран | `F` |
| Обзор всех слайдов | `Esc` |
| PDF-экспорт (аварийный план) | добавить `?print-pdf` к адресу → печать в PDF (в диалоге печати включить «Фоновая графика», иначе акцентные слайды выйдут белыми) |

### Стек демок

React 18 + canvas, тот же, что в коллекции `Demo/` — оттуда переносятся готовые демки (Тономура, волновой пакет, облако). Библиотеки лежат в `shared/vendor/` **один раз на все демки**, а не зашиваются в каждый файл, как в старой коллекции.

JSX без сборки даёт [htm](https://github.com/developit/htm) (1,4 КБ): синтаксис почти как JSX, но компиляции не требует. Babel в рантайм не тащим — он весит 2,9 МБ и добавлял бы задержку при открытии каждого слайда с демкой. Node.js для сборки не нужен.

Главное отличие от старой коллекции: **стили демок не инлайновые**. Весь вид задаётся классами из `shared/demo.css` — там же токены палитры. На этапе Claude Design правится один файл, и меняются сразу все демки; логика и разметка не трогаются.

Демка «Турбулентности» объявляет `class="turb"` на `<html>` и получает бирюзовые токены вместо янтарных. Ещё два модификатора: `class="bare"` — страница отдаёт фон слайду (для рисунков без рамки прибора), а класс `panel` вместо `stage` ставит на место канвы обычную вёрстку. Последнее нужно там, где анимировать нечего, а набирать математику есть чем: KaTeX подключается в саму демку из `shared/vendor/katex`, и формулы набираются им, а не рисуются на канве.

### Типы блоков

| Блок | Что делает |
|---|---|
| `lead` | одна крупная мысль акцентным цветом |
| `bullets` | маркированный список |
| `formula` | плашка с формулой и подписью (`size: 'small'` для длинных) |
| `compare` | две карточки рядом |
| `demo` | интерактивная демка; без `src` — пунктирная заглушка |
| `video` | видео: локальный файл → `<video>` (офлайн), URL → iframe (нужна сеть) |
| `image` | картинка с подписью |
| `row` | горизонтальный ряд вложенных блоков |
| `derive` | разбор по шагам: строки `{ tex, note }` |

У `formula` есть `tex` — формула набирается LaTeX'ом и рендерится KaTeX. У `bullets` есть `reveal: true` — пункты открываются по одному. У `demo` есть `bare: true`: рамка, фон и тень снимаются, и на слайде остаётся рисунок, а не панель прибора (страница демки объявляет тогда `class="bare"` на `<html>`). Колода целиком может объявить `meta.plain` и отказаться от анимаций и эффектов темы.

Слайд может объявить `smoke: true` — на нём живёт фоновая струя «Турбулентности». Слайдов подряд может быть несколько, и на границе между ними струя не перезапускается.

У `video` есть `start` / `end` (секунды, показывается только фрагмент), `autoplay`, `loop`, `muted`. Слайду можно задать `layout: 'media'` — обвязка ужимается, кадру отдаётся максимум высоты.

`image` умеет измерение поверх снимка: `natural: [ширина, высота]` в пикселях файла и `marks` — список шагов, каждый выходит по клику. Шаг это набор примитивов `line` (`from`, `to`), `arc` (`at`, `r` — верхняя полудуга) и `text` (`at`, `text`, `anchor`). Координаты задаются в пикселях исходного файла, поэтому размечать можно прямо по нему. Так на слайде 8 «Турбулентности» радиус огненного шара меряется на глазах у зала.

### Принципы

1. **Offline-first.** Ноль CDN и внешних запросов, ноль этапов сборки. Библиотеки и медиа лежат в репозитории. Единственное исключение — YouTube-вставки, и каждая помечена в заметках как требующая сети.
2. **Контент отдельно от движка.** Слайды — данные в `slides.js`, собранные из семантических типов блоков. Движок и тема ничего не знают о конкретной лекции.
3. **Дизайн — потом.** Тема намеренно минимальная («белый фон, системный шрифт, пунктиры для заглушек»). Финальный визуал делается этапом Claude Design: он переопределяет CSS-токены и стили блоков, не трогая контент.
4. **Демки — внутри слайдов.** Блок `demo` сейчас рендерит пунктирную заглушку; когда демка готова, добавляется `src` — и она встраивается iframe'ом с ленивой загрузкой (reveal `data-src`). ⚠️ Из `Demo/` подключать только офлайн-версии (с зашитым React); обычные тянут библиотеки с CDN и без сети молча умирают.
5. **Текст — по [STYLE.md](STYLE.md).** Слайд не конспект: методика, реквизит и режиссёрские ходы живут в заметках докладчика, потому что есть спикер-вью.

### Заметки докладчика

Лежат в `slides.js` у каждого слайда (`notes`) и попадают в режим докладчика (`S`). Это ключевые мысли из планов лекций — не терять при правках.
