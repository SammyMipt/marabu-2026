# Марабу 2026 — веб-презентации лекций

Две лекции для лагеря Марабу (Массачусетс, лето 2026):

- **«Электрон»** — квантовая механика, младшая группа (11–14). Часть миникурса Сергея, третья лекция из четырёх.
- **«Течения и турбулентность»** — классическая физика, старшая группа (14–18). Полностью standalone.

Каноничные планы лекций: `lekciya_elektron_plan.md`, `lekciya_turbulentnost_plan.md`, полный контекст решений — `marabu_kontekst.md`. Контент слайдов следует планам дословно; отклонения — только через явное обсуждение.

## Как открыть

Никакой сборки нет. Открой `index.html` (лендинг) или сразу колоду:

- `elektron/index.html`
- `turbulentnost/index.html`

Работает с диска (file://) и без интернета — это принципиальное требование: в лекционном зале сети может не быть.

## Управление на лекции

| Действие | Клавиша |
|---|---|
| Слайды вперёд/назад | стрелки, пробел, PageDown/PageUp (кликер) |
| Режим докладчика (заметки + таймер + следующий слайд) | `S` |
| Полный экран | `F` |
| Обзор всех слайдов | `Esc` |
| PDF-экспорт (аварийный план) | добавить `?print-pdf` к адресу → печать в PDF (в диалоге печати включить «Фоновая графика», иначе акцентные слайды выйдут белыми) |

## Устройство

```
index.html               — лендинг со ссылками на обе колоды
elektron/                — колода «Электрон»
  index.html             — обвязка (стили + скрипты)
  slides.js              — ВЕСЬ контент колоды (window.DECK)
turbulentnost/           — колода «Турбулентность» (та же структура)
shared/
  deck.js                — рендер: spec из slides.js → секции reveal.js
  theme/base.css         — минимальная тема: типы блоков, раскладка
  theme/electron.css     — палитра индиго (только CSS-токены)
  theme/turbulence.css   — палитра бирюза (только CSS-токены)
  reveal/                — вендоренный reveal.js 5.2.1 (dist + плагин notes)
Demo/                    — коллекция готовых интерактивных демок (исходный материал)
```

### Принципы

1. **Offline-first.** Ноль CDN и внешних запросов, ноль этапов сборки. Библиотеки вендорятся в репозиторий.
2. **Контент отдельно от движка.** Слайды — данные в `slides.js`; собираются из шести семантических типов блоков: `lead`, `bullets`, `formula`, `demo`, `live`, `compare` (+ `video`). Движок и тема ничего не знают о конкретной лекции.
3. **Дизайн — потом.** Тема намеренно минимальная («белый фон, системный шрифт, пунктиры для заглушек»). Финальный визуал делается этапом Claude Design: он переопределяет CSS-токены и стили блоков, не трогая контент.
4. **Демки — внутри слайдов.** Блок `demo` сейчас рендерит пунктирную заглушку; когда демка готова, добавляется `src` — и она встраивается iframe'ом с ленивой загрузкой (reveal `data-src`). ⚠️ Из `Demo/` подключать только офлайн-версии (с зашитым React); обычные тянут библиотеки с CDN и без сети молча умирают.

### Заметки докладчика

Лежат в `slides.js` у каждого слайда (`notes`) и попадают в режим докладчика (`S`). Это ключевые мысли из планов лекций — не терять при правках.
