# Бриф на оформление

Колоды намеренно свёрстаны в минимальной теме, чтобы визуал делался отдельным этапом. Этот файл описывает, что можно трогать, что нельзя и почему.

## Что это за проект

Две лекции для детского научного лагеря: «Электрон» (дети 11–14) и «Течения и турбулентность» (подростки 14–18). Показываются с ноутбука на проекторе в лагерном зале. Автор читает их сам.

## Правьте эти файлы

| Файл | Что в нём |
|---|---|
| `shared/theme/base.css` | вся вёрстка слайда: типы блоков, раскладка, размеры |
| `shared/theme/electron.css` | палитра «Электрона» — только переменные |
| `shared/theme/turbulence.css` | палитра «Турбулентности» — только переменные |
| `shared/demo.css` | весь вид интерактивных демок |

## Не трогайте эти

| Файл | Почему |
|---|---|
| `elektron/slides.js`, `turbulentnost/slides.js` | контент лекций, выверен с автором построчно |
| `shared/deck.js` | движок, собирает слайды из данных |
| `demos/*.html` | логика демок; их внешний вид задаётся из `shared/demo.css` |
| `media/` | видео и картинки, лицензии в `media/CREDITS.md` |

## Жёсткие ограничения

**Никакой сети.** В зале может не быть интернета. Ни одного `@import` со шрифтами, ни CDN, ни внешних картинок — всё, что нужно, кладётся в репозиторий файлом. Сейчас внешняя ссылка в проекте ровно одна, и это осознанная YouTube-вставка на одном слайде.

**Никакой сборки.** Node.js на машине автора нет. Ни препроцессоров, ни сборщиков: только обычный CSS, который читает браузер.

**Читаемость с десяти метров.** Это лекционный зал, а не экран ноутбука. Основной текст сейчас 24–25 px при слайде 1280×720, мельче делать нельзя. Тонкие начертания и низкий контраст не подойдут.

**Слайд ровно 1280×720.** Масштабированием занимается reveal.js, вёрстка от размера окна не зависит.

**Режим докладчика.** Клавиша `S` открывает окно с заметками — оно наследует ту же тему, проверяйте и его.

**Печать в PDF.** Адрес с `?print-pdf` — аварийный план на случай чужого компьютера. После правок стоит проверить, что слайды не разъезжаются.

## Как устроена тема

Все цвета берутся из переменных, объявленных в палитрах:

```css
--bg          /* фон слайда */
--ink         /* основной текст */
--muted       /* подписи, второстепенное */
--accent      /* акцент: заголовки-кикеры, формулы, лид */
--chip        /* заливка карточек и плашек */
--demo-fill   /* заливка блока с демкой */
--title-sub   /* текст на акцентном фоне титула и финала */
--font-head   /* заголовки */
--font-body   /* текст */
```

Типы блоков, из которых собираются слайды: `lead` (крупная мысль), `bullets`, `formula` (плашка с формулой и подписью), `compare` (две карточки), `demo` (интерактивная демка), `video`, `image`, `row` (горизонтальный ряд). Плюс акцентные слайды `title` и `closing` и модификатор `layout: 'media'`, который ужимает обвязку ради кадра.

⚠️ **Демки живут в iframe и переменных страницы не наследуют.** Поэтому палитра демок продублирована в начале `shared/demo.css`. Меняя палитру колоды, синхронизируйте её там же, иначе демки останутся в старых цветах.

⚠️ **Внутри демок рисует canvas.** Цвета графики (электроны, кривые, экран) заданы в коде демок и CSS их не достаёт. Если палитра меняется существенно, скажите об этом автору — правки в коде демок сделает он.

## Что стоит улучшить

Список от автора вёрстки, не обязательный к исполнению:

- Титул и финал сейчас просто заливка акцентным цветом — просятся в что-то более интересное.
- Блок `formula` — обычная серая плашка, а формула в лекции ровно одна и она кульминация беата.
- `compare` не различает левую и правую карточки, хотя по смыслу они часто противопоставлены.
- Заголовок и кикер визуально почти не связаны.
- Заметок для докладчика оформление не касалось вовсе.
